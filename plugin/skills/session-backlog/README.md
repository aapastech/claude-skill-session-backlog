# Aapastech Session Backlog (skill folder)

- `SKILL.md`: the rules the assistant follows every session.
- `scripts/bl.py`: the backlog engine. Copied into `~/Documents/Aapastech-Backlog` on first run. Stdlib-only Python 3.8+, macOS / Windows / Linux.
- `scripts/backlog_mcp.py`: MCP server wrapping the engine, for any MCP client or model.

Full instructions: https://github.com/aapastech/claude-skill-session-backlog
